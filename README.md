# SOC Alert Investigation

## Project Overview

This project demonstrates a simulated Security Operations Center (SOC)
investigation involving suspicious authentication activity.

The investigation focuses on analyzing login attempts, identifying
potential indicators of compromise (IOCs), establishing an incident
timeline, and recommending appropriate response actions.

## Scenario

A corporate VPN generated an alert after detecting multiple failed
authentication attempts against a user account, followed by a successful
authentication from the same source IP address.

### Alert Information

- Alert ID: SOC-2026-001
- Alert Type: Multiple Failed Login Attempts
- Severity: Medium
- User: j.smith
- Source IP: 185.XXX.XXX.42
- Destination: Corporate VPN
- Date: 17 September 2026

## Investigation Objectives

The objectives of this investigation are to:

1. Analyze the authentication activity.
2. Identify suspicious patterns.
3. Determine whether the activity may indicate account compromise.
4. Identify relevant indicators of compromise.
5. Establish an incident timeline.
6. Recommend appropriate response actions.

## Skills Demonstrated

- Security alert triage
- Authentication log analysis
- Incident investigation
- Indicator of Compromise (IOC) identification
- Incident timeline development
- Risk assessment
- Incident response documentation

## Investigation

Investigation findings will be documented as the analysis progresses.

## Conclusion

The final assessment will be based on the available evidence and
documented investigation findings.
